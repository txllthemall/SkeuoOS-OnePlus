# SkeuoOS Liquid27 for OnePlus

An Android icon pack for the stock OnePlus / OxygenOS launcher, rebuilt in v3 around the current iOS 27 Liquid Glass design language.

## v3.0.0

- **66 original Liquid27 icons** generated by this project
- **152 Android component mappings** including OnePlus/Oppo/ColorOS and common third-party apps
- 768 px working renders downsampled to 512 px for clean edges
- layered glass material with simulated refraction
- sharper edges and stronger contrast than the previous iOS 26-style glass look
- restrained translucency so glyphs stay readable
- fixed top/bottom specular highlights rather than motion shimmer
- simplified, optically balanced foreground shapes
- OnePlus discovery intent: `net.oneplus.launcher.icons.ACTION_PICK_ICON`
- standard `appfilter.xml` + `drawable.xml` in both `assets/` and `res/xml/`
- no ads, analytics, trackers, network permission, or background service

v3 does **not** bundle the old `zagnut531/iOS-6-Icons` collection. The v0.2.0 release remains available separately for anyone who wants that archive-based build.

## Design direction

The generator follows the design principles Apple currently documents for Liquid Glass app icons: layered artwork, strong optical balance, selective translucency/refraction, dimensional separation, and crisp specular definition. iOS 27 specifically moves toward sharper, more detailed icon layers with less of the washed-out look associated with early Liquid Glass rendering.

The artwork in this repository is original procedural artwork inspired by that design language. It is **not** an extraction of Apple's iOS 27 assets.

## Install on OnePlus / OxygenOS

1. Download the latest APK from **Releases**.
2. Install it over the previous SkeuoOS build if present.
3. Open **Settings → Wallpapers & style → Icons**.
4. Select **SkeuoOS Liquid27**.
5. If an app does not match automatically, long-press its icon and choose a pack icon manually.

## Build

```bash
python3 -m pip install Pillow==11.3.0
python3 tools/generate_liquid27.py
python3 tools/check_pack.py
gradle :app:assembleDebug
```

The generator also writes `build/liquid27-preview.png` so a CI build can be inspected without installing the APK.

## Adding mappings

Mappings cover apps such as Discord, Google Play, YouTube/ReVanced, Kaspi, 2GIS, Photos/Gallery, Gmail, SoundCloud, Telegram, Recorder, Phone, Messages, Camera and Chrome, plus a wider common-app catalog.

To add another automatic mapping, add its Android component to `appfilter.xml` and point it at an existing drawable resource.
