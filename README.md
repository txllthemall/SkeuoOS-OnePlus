# SkeuoOS OnePlus

A skeuomorphic Android icon pack designed first for the stock OnePlus / OxygenOS launcher.

![preview](docs/preview.png)

## v0.2.0

- **591 packaged icon resources**
- **525 icons imported from `zagnut531/iOS-6-Icons`** at build time
  - 247 third-party icons
  - 142 Apple icons
  - 58 iPad icons
  - 78 iPhone & iPod touch icons
- **66 SkeuoOS fallback icons** generated by this project
- **152 Android component mappings** including OnePlus/Oppo/ColorOS and common third-party apps
- 35 common automatic mappings are replaced with matching upstream iOS 6 artwork when available
- Full upstream collection is exposed in the icon picker for manual selection
- OnePlus discovery intent: `net.oneplus.launcher.icons.ACTION_PICK_ICON`
- Standard `appfilter.xml` + `drawable.xml` in both `assets/` and `res/xml/`
- No ads, analytics, trackers, network permission, or background service

## Install on OnePlus / OxygenOS

1. Download the latest APK from **Releases**.
2. Install it.
3. Open **Settings → Wallpapers & style → Icons**.
4. Select **SkeuoOS**.
5. If an app does not match automatically, long-press its icon and pick the desired iOS 6 icon manually.

## Build

The upstream image archive is intentionally not committed into this repository. The importer downloads it during the build, converts supported images to Android-safe PNG resources, repairs truncated images where possible, limits them to 512 px, generates picker entries, and overlays matching artwork onto known Android mappings.

```bash
python3 -m pip install Pillow==11.3.0
python3 tools/generate_icons.py
python3 tools/import_zagnut_ios6.py
python3 tools/check_pack.py
gradle :app:assembleDebug
```

The importer writes `build/ios6-import-report.json` with exact counts, source paths and automatic overlays.

## Adding mappings

The starter mappings cover apps such as Discord, Google Play, YouTube/ReVanced, Kaspi, 2GIS, Photos/Gallery, Gmail, SoundCloud, Telegram, Recorder, Phone, Messages, Camera and Chrome, plus a wider common-app catalog.

To add another automatic mapping, add its Android component to `appfilter.xml` and point it at an existing drawable. The entire upstream collection remains available through the manual icon picker even without a component mapping.
